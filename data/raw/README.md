# Raw data

The IBM Telco Customer Churn sample CSV is downloaded here by `python -m src.download_data`.

Expected filename: `Telco-Customer-Churn.csv`

Do not edit the raw source file. The dataset represents a fictional telecommunications provider and is intended as a learning/sample dataset, not real customer records.

Source: IBM public repository:
https://github.com/IBM/telco-customer-churn-on-icp4d
Direct CSV:
https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv

Expected source dimensions: 7,043 rows × 21 columns.
