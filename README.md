# Customer Churn Analysis & Prediction

An end-to-end machine learning portfolio project using the **IBM Telco Customer Churn sample dataset**. It includes data acquisition, cleaning, exploratory analytics, model comparison, churn prediction, and a Streamlit dashboard.

> Dataset note: this is a public sample for a fictional telecommunications provider, not a dataset of actual customers. The source contains 7,043 rows and 21 columns. The project does not claim that its results generalize to a real telecom business.

## Features

- Reproducible dataset downloader with SHA-256 verification
- Data cleaning (including blank `TotalCharges` values)
- Exploratory charts and churn analysis
- Five classifiers: Logistic Regression, Decision Tree, Random Forest, Gradient Boosting, and Hist Gradient Boosting
- Stratified 80/20 train-test split
- Accuracy, precision, recall, F1-score, ROC-AUC, classification report, and confusion matrix
- Best model selected by held-out test F1-score
- Streamlit dashboard with overview, customer insights, interactive single-customer prediction, and model metrics
- Downloadable source dataset and generated reports after setup

## Setup on Windows PowerShell

Open PowerShell in the project folder:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If PowerShell blocks activation, use:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\venv\Scripts\Activate.ps1
```

## Download data and train models

```powershell
python -m src.download_data
python -m src.train
```

The downloader retrieves the IBM CSV and verifies its SHA-256 checksum before saving it. The training pipeline creates:
- `data/processed/telco_churn_clean.csv`
- `models/best_churn_model.joblib`
- `reports/model_comparison.csv`
- `reports/best_model_metrics.json`
- `reports/classification_report.txt`
- `reports/confusion_matrix.png`

## Run the dashboard

```powershell
streamlit run app.py
```

Streamlit will display a local URL (usually `http://localhost:8501`) in the terminal.

- IBM public sample repository: https://github.com/IBM/telco-customer-churn-on-icp4d
- Direct CSV: https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv
- The repository is archived and read-only.
- Expected source file: 7,043 records × 21 columns.
- The `Churn` target is encoded as `1 = Yes` and `0 = No`.

Review the original repository terms before redistributing the raw dataset. This project downloader fetches the dataset from IBM rather than bundling a copy in this ZIP.

## Methodology

1. Exclude `customerID` from model features because it is an identifier.
2. Convert `TotalCharges` to numeric; blank values are set to zero (the source blanks correspond to new customers with zero tenure).
3. Use median imputation and standard scaling for numeric features.
4. Use most-frequent imputation and one-hot encoding for categorical features.
5. Split data with stratification and a fixed random seed.
6. Compare all five classifiers on the same held-out test set.
7. Select the model by F1-score and save the full preprocessing/model pipeline.

## Important interpretation notes

- Churn prediction is a classification task on a cross-sectional labelled sample.
- This dataset does not provide a sequence of monthly snapshots for time-based backtesting.
- A random held-out test score is not proof of future-month performance or real-world business impact.
- The app's default 0.50 probability threshold is illustrative. A real retention team should choose a threshold based on intervention cost, capacity, and validated business outcomes.
- Do not claim a specific model accuracy on your resume until you run the training script and use the resulting metrics.
